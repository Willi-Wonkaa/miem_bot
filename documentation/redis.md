# Redis

Контейнер `redis` задаётся в `compose.yaml`. Он хранит краткую историю основного бота, блокировки параллельных вопросов и данные с TTL. Это не архив переписок: долговременный архив находится в отдельной SQLite-базе.

`app/telegram/history.py` использует ключ `history:<chat>:<user>`: последние пять пар вопрос/ответ, TTL по умолчанию 24 часа. Ключ `lock:<chat>:<user>` не даёт обработать два запроса одновременно в одной сессии; освободить его может только владелец. Команда `/reset` удаляет историю текущей сессии.

Redis настроен с AOF и volume `redis-data`, лимит памяти — 256 MiB, политика при заполнении — `noeviction`. Состояние проверяет healthcheck `redis-cli ping`. Основной бот зависит от здорового Redis; RAG API от него не зависит.
