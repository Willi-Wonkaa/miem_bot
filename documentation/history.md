# Переписки и оценки ответов

Основной бот сохраняет все полученные сообщения пользователя и свои отправленные сообщения в SQLite. Полный ответ модели хранится отдельно с временем готовности, названием модели и связью с вопросом. У вложений сохраняются метаданные Telegram; сами файлы не скачиваются.

На сервере база находится в `/opt/miem-bot/shared/history/conversations.sqlite3`. Основной и сервисный бот используют одну базу в режиме WAL. Она сохраняется при обновлении контейнеров. Автоматического удаления истории нет. Запись начинается после установки этой версии: прошлые сообщения Telegram восстановить через Bot API нельзя.

Redis хранит только последние пять пар сообщений для контекста модели на 24 часа. Команда `/reset` очищает этот контекст, а постоянный архив сохраняется.

Под каждым ответом находятся кнопки «Помог ответ» и «Не помог». Первое нажатие сохраняет оценку и убирает обе кнопки. Без нажатия кнопки исчезают через 10 минут от времени отправки сообщения. Состояние и срок хранятся в SQLite: перезапуск бота не начинает отсчёт заново.

В таблице `feedback` поле `helpful` содержит `-1` (не помог), `0` (оценка не поставлена) или `1` (помог). Сохраняются время оценки, идентификатор ответа и вопроса. После отрицательной оценки бот спрашивает «Что не так?». Ответить нужно на это сообщение через Telegram Reply. Комментарий сохраняется как сообщение в переписке и связывается с исходным ответом; он не отправляется модели как новый вопрос. История оценок и комментариев находится в `feedback_events`.

Просмотр в сервисном боте доступен только идентификаторам из `SERVICE_ADMIN_IDS` — JSON-массива Telegram user ID в серверном `.env`. При пустом списке доступ закрыт для всех.

- `/users` — список пользователей; `/users ID` или `/users @username` — поиск.
- `/history USER_ID` — сообщения выбранного пользователя, время, ответы и оценки.
- `/history USER_ID 2026-10-13 2026-10-14` — период, обе даты включены.
- `/export USER_ID` — полная выгрузка в JSON.

В сервисном боте время показано в `TIMEZONE` (по умолчанию Москва), в базе и JSON — UTC. Выгрузка содержит одного пользователя и всю его переписку, ответы модели, оценки и комментарии. Для резервного копирования работающей базы используйте SQLite backup; копировать только основной файл при активном WAL недостаточно.
