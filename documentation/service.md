# Служебный Telegram-бот

Точка входа — `app/service/bot.py`, контейнер `service`. Использует отдельный `SERVICE_BOT_TOKEN` и long polling. Он стартует первым и показывает состояние приложения, прогресс базы и статистику запросов. Настройки подписок сохраняются в `monitor-data/control.sqlite3` через `app/telemetry.py`.

| Команда | Что показывает |
| --- | --- |
| `/start`, `/status` | Подписка на уведомления, состояние компонентов и ресурсов |
| `/index`, `/progress` | Документы, ошибки, состояние индексаторов и ETA |
| `/requests`, `/stats` | Запросы к RAG API за 1/5/30 минут и суммарно |

Кнопки позволяют обновить экран и настроить виды уведомлений. Обычная подписка через `/start` в личном чате сейчас доступна любому пользователю этого бота; whitelist для статуса нет.

`app/service/history.py` добавляет `/users`, `/history USER_ID [YYYY-MM-DD YYYY-MM-DD]` и `/export USER_ID` для просмотра/выгрузки долговременных переписок. Доступ проверяется по Telegram ID в `SERVICE_ADMIN_IDS`. При пустом списке никто не получает доступ к архиву. Эта функция читает тот же SQLite-файл, который пишет основной бот. Compose монтирует общий каталог в оба контейнера; на VPS база находится в `/opt/miem-bot/shared/history/`. Подробности — в [переписках и оценках](history.md).

Администраторам доступна кнопка «Выгрузка логов». В ней можно скачать каждый текущий `*.txt` из `LOG_DIR` под понятным названием, один `all-chats-*.json` со всеми пользователями и их сообщениями, ответами модели и оценками или один `all-logs-and-chats-*.zip` со всеми этими файлами. ZIP приходит одним сообщением. В подписи указаны содержимое, время выгрузки в `TIMEZONE` и размер отправляемого файла. JSON устроен как `{"users": [{"user": ..., "messages": [...], "answers": [...], "feedback": [...], "feedback_events": [...]}]}`; временные поля в нём — UTC. Доступ к каждой кнопке повторно проверяется по `SERVICE_ADMIN_IDS`.

Полные тексты вопросов и ответов не записываются в `control.sqlite3`. Он хранит счётчики, события, состояния и подписки. Текстовый лог служебного бота — `shared/logs/service.txt`.
